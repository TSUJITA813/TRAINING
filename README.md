# トレーニングメモ（Android / Flutter）

ウエイトトレーニングの記録を「メモ帳と同じ書き方のまま」爆速で入力し、整形表示・履歴活用・AI/トレーナーへの共有まで行う個人用アプリです。

## 主な機能

| 画面 | 機能 |
|---|---|
| 記録 | 日付ごとの体重・歩数・トレーニングメニュー・コンディションメモ。入力は自動保存 |
| 履歴 | 日付別一覧（検索・削除・今日へコピー）、種目別の推移（最高重量・推定1RM） |
| 身体 | 身長・体重の保存、BMI、体重の推移グラフ |
| 設定 | 歩数の取得方法、JSONバックアップ／復元、メモ帳からの一括取り込み |

### トレーニングメニューの書き方

```
【試合前A】2026/11/10
RPD 90@4 90@4 RPDW 45@5✕
PSQ 175@2  175@2
BSQ 130@2x3
懸垂 @10 @8
# 腰に張りあり
```

- `重量@回数`（kg）。1行に複数種目OK
- `✕` 失敗レップ／`x3` 同じ内容を3セット／重量省略で自重
- `#` `※` `//` で始まる行はメモ
- 入力中はキーボード上に補助バー：`@`、**同じセット**（直前のセットを複製）、**前回の内容**（その種目の前回のセットを挿入）、よく使う種目のチップ
- 下の整形表示に、種目ごとのセット・総挙上量・前回との比較を表示。種目名タップで履歴

### 歩数

1. **ヘルスコネクト連携（推奨・初期設定）**：Google Fit / Mi Fitness などがヘルスコネクトに書き込んだ歩数を読み込みます。アプリを閉じていても欠けません。
2. **端末の歩数センサー**：アプリ単体で計測。Android の制約上、アプリを開いたときの累計値との差で計算するため誤差が出ることがあります。
3. **手入力**：歩数欄をタップ。

### 共有・バックアップ

- 記録画面の「日報をコピー」で、日付・体重・歩数（距離・消費カロリー概算）・メニュー（種目別詳細つき）・コンディションメモをまとめてクリップボードへ。ChatGPT やトレーナーにそのまま貼り付けられます。
- 設定 → バックアップで JSON ファイルを保存／他アプリへ送信／復元（統合 or 置き換え）。
